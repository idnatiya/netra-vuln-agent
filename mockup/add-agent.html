Add agent

Run one command on a VM. The agent installs itself, enrolls, and sends its first scan here.

  1. 1

    Choose the client

    The VM's findings belong to this client.

    Create a client
  2. 2

    Run the install command on the VM

    As root or with sudo. Safe to run again to update.

    $ curl -fsSL https://vuln.example.com/install.sh | sudo NETRA_ENROLL_TOKEN=nvt_acme_7Qm2xR9kLp4vT8sW sh

    The command contains acme's enroll token. Anyone with it can add hosts to acme; share it only with people who manage these VMs.

    Download the binary from the GitHub Release, check it, install, then enroll:

    a=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/') u=https://github.com/idnatiya/netra-vuln-agent/releases/latest/download curl -fsSLO "$u/vuln-agent-linux-$a" -fsSLO "$u/SHA256SUMS" grep " vuln-agent-linux-$a\$" SHA256SUMS | sha256sum -c - \ && chmod +x "vuln-agent-linux-$a" && sudo "./vuln-agent-linux-$a" install # set central_url: https://vuln.example.com and client_id: acme sudoedit /etc/vuln-agent/config.yaml echo nvt_acme_7Qm2xR9kLp4vT8sW | sudo vuln-agent enroll
    • • Ubuntu/Debian, AlmaLinux/Rocky/CentOS · amd64, arm64
    • • Outbound HTTPS to vuln.example.com and github.com
    • • Installs to /opt/vuln-agent, config in /etc/vuln-agent
    • • Daily scan + heartbeat every 15 min (systemd timers)
